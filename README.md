# SomJing (สมจริง) — Rare Collectibles & Authentic Goods E-Commerce Prototype

**SomJing (สมจริง)** เป็นโปรแกรมต้นแบบระบบ E-Commerce สำหรับซื้อขายและประมูลของสะสม สินค้าแรร์ อาร์ตทอย สนีกเกอร์ แก็ดเจ็ตเรโทร และนาฬิกา/การ์ดสะสม ที่มาพร้อม **ระบบตรวจรับรองความแท้ (Verified Badge)**, **กระดานตามหาสินค้า (Wanted Listing)** และ **ระบบพักเงินตัวกลาง 4 ขั้นตอน (Escrow Payment Protection)**

> 📄 เอกสารประกอบรายงานวิชา E-Commerce (บทที่ 5 หัวข้อ 5.1 – 5.7 ฉบับสมบูรณ์พร้อมผัง Mermaid) อยู่ในไฟล์ [`CHAPTER_5_REPORT.md`](./CHAPTER_5_REPORT.md)

## ฟีเจอร์หลัก (Core MVP)

1. **สมัครสมาชิก / เข้าสู่ระบบ** แยกบทบาท (ผู้ซื้อ / ผู้ขาย / แอดมิน) พร้อมแถบ **สลับบทบาทด่วน (Quick Role Switcher)** และปุ่ม **รีเซ็ตข้อมูลตัวอย่าง** สำหรับการนำเสนอ
2. **หน้ารวมสินค้า + ค้นหาตามหมวดหมู่** ค้นหาชื่อสินค้าหรือเลข Certificate ID กรองตามหมวดหมู่ ประเภทการขาย (ประมูล / ซื้อทันที) และตัวกรองเฉพาะสินค้าที่ผ่าน Verified Badge
3. **หน้าสินค้าประมูล (Live Auction)** แสดงราคาปัจจุบัน เวลานับถอยหลังแบบเรียลไทม์ ปุ่มบิดประมูลด่วนและบิดกำหนดเอง ประวัติการบิด และ Verified Badge พร้อมเลขที่ใบรับรอง
4. **ลงขายสินค้า** สร้างประกาศขายแบบเปิดประมูลหรือราคาคงที่ พร้อมตัวเลือกส่งคำขอ Verify ในขั้นตอนเดียว
5. **ขอ Verify** ส่งคำขอตรวจรับรองความแท้พร้อม Serial Number และหลักฐานภาพถ่าย
6. **Wanted Listing (Reverse Marketplace)** ผู้ซื้อสร้างประกาศตามหาสินค้าพร้อมงบประมาณ ผู้ขายยื่นข้อเสนอแข่งกัน และผู้ซื้อเลือกข้อเสนอเพื่อชำระเงินเข้า Escrow ทันที
7. **ชำระเงินจำลอง + สถานะ Escrow** จำลองการชำระเงินผ่าน PromptPay QR / บัตรเครดิต / แอปธนาคาร พร้อมติดตามสถานะ 4 ขั้นตอน (`พักเงิน → จัดส่ง → ยืนยันรับของ → ปล่อยเงิน`) และระบบแจ้งข้อร้องเรียน
8. **หน้าแอดมิน (Admin Console)** คิวตรวจและอนุมัติ/ปฏิเสธ Verified Badge (ออก Certificate ID อัตโนมัติ) และจัดการข้อร้องเรียนเพื่อตัดสินคืนเงินผู้ซื้อหรือปล่อยเงินให้ผู้ขาย

## เทคโนโลยีที่ใช้พัฒนา

- **React 18** + **TypeScript 5**
- **Vite 5** + **Tailwind CSS 3**
- **Lucide React**
- **LocalStorage Persistence** + Seed Data (`src/data/seedData.ts`)

## การติดตั้งและรันใช้งานบนเครื่อง (Local Setup)

```bash
npm install
npm run dev
```

Build สำหรับ Production:

```bash
npm run build
```
